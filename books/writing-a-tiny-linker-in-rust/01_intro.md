リンカーとは、コンパイラが生成したオブジェクトファイル（`.o`ファイル）を結合して実行ファイルを作るソフトウェアである。

普段プログラミングをしているとコンパイルから実行ファイル生成まで一気に走ってしまうので、リンカーの存在を意識する機会は少ないではないかと思う。
だが実際にはコンパイラとリンカーは別物で、リンカーがいないとそもそも実行ファイルは作れない。

本書ではRustで小さなリンカーをゼロから実装して、最終的には次のような小さなプログラムを自作リンカーでリンクして、ちゃんと実行できる状態を目指す。

```c:main.c
__asm__(
      ".global _start\n"
      "_start:\n"
      "    adr     x0, x\n"
      "    ldr     w0, [x0]\n"
      "    mov     x8, #93\n"
      "    svc     #0\n"
);
```

```c:sub.c
int x = 11;
```

`main.c`は変数`x`の値を読み取って終了ステータスにするだけのアセンブリで、`sub.c`はその`x`を定義しているだけのコードである。
これらをコンパイルして自作リンカーでリンクすると、終了ステータスに`11`を返す実行ファイルができ上がる、というのが本書のゴールである。

```sh
$ gcc -c main.c -o main.o && gcc -c sub.c -o sub.o
$ ./tiny-linker a.out main.o sub.o
$ ./a.out
$ echo $?
11
```

本書を通して理解できるようになることは次のとおり。

- ELFバイナリのデータ構造
- シンボル解決の仕組み
- セクションの配置と結合
- 再配置（リロケーション）の仕組み
- ELFバイナリのデコードの実装
- リンク処理の実装

## 対象の読者

本書の対象者は次のとおり。

- Rustの基礎をわかっていて、読み書きができる人
- リンカーに興味がある人
- リンカーの動作原理を知りたい人

## 用語

本書で使う用語は次のとおり。

| 用語                     | 説明                                                                                                     |
| ------------------------ | -------------------------------------------------------------------------------------------------------- |
| リンカー                 | オブジェクトファイルを結合して実行ファイルを生成するソフトウェア                                     |
| オブジェクトファイル     | コンパイラがソースコードをコンパイルした結果の中間ファイル（`.o`ファイル）                               |
| 実行ファイル         | OSが直接実行できるファイル                                                                               |
| ELF                      | Executable and Linkable Format。Unix/Linuxで使われるオブジェクトファイルと実行ファイルのフォーマット |
| シンボル                 | 変数名や関数名などの識別子。シンボルテーブルに格納される                                                 |
| セクション               | オブジェクトファイル内のコードやデータを論理的に分割した単位（`.text`、`.data`など）                     |
| 再配置（リロケーション） | シンボルの参照先アドレスを実際のメモリアドレスに調整する処理                                             |
| 静的リンク               | リンク時にすべてのオブジェクトファイルを結合する方式                                                     |
| 動的リンク               | 実行時に共有ライブラリをリンクする方式                                                                   |

## 本書で実装するリンカー

本書で実装するリンカーは次のとおり。

- ターゲット: ARM64（AArch64）Linux
- フォーマット: ELF64
- リンク方式: 静的リンク
